# Code of Conduct

## Our standard

Azura Moki is an open project for Roblox and Luau developers. Participants are expected to be respectful, inclusive, and constructive. Give feedback about the code and its impact, not about a contributor's identity or assumed intentions.

## Expected behavior

Contributors should communicate professionally, welcome different experience levels, explain disagreements with evidence, respect project boundaries, and protect private information. Share only code, assets, and examples that you are allowed to distribute.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, deliberate exposure of private data, sexualized content involving minors, spam, malicious code, credential theft, or instructions intended to compromise accounts or experiences are not acceptable. Do not use this project to target players or bypass platform safety and security controls.

## Enforcement

Project maintainers may edit or remove comments, close issues or pull requests, or restrict participation when behavior violates this code. The response will be proportional to the conduct and focused on keeping the project safe and useful.

To report a concern, contact a repository maintainer through GitHub with a clear description, links, and any relevant evidence. Do not publish sensitive personal information in an issue or pull request.

## Scope

This code applies in the repository, its issues and pull requests, project discussions, and project-related community spaces when someone is representing the project.
